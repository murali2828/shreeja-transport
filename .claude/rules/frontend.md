# Frontend rules

- All HTTP goes through `frontend/src/api/index.js` (one axios instance, Bearer token,
  auto-logout on 401); add a named helper there, never import axios in a page.
- Data fetching with TanStack Query: `useQuery({ queryKey, queryFn })`, writes with
  `useMutation` and `qc.invalidateQueries([...])` on success; `toast.success/error` for
  feedback (`e.response?.data?.error || e.message`).
- Pages live in `src/pages/<module>/PascalCase.jsx`; shared UI comes from
  `components/MasterTable.jsx` (`Modal`, `Field`, `SaveButton`, `PageHeader`, `EmptyState`,
  `LoadingState`, `ActiveBadge`) and `SearchableSelect`; icons from `lucide-react`.
- New routes go in `App.jsx` inside the `ProtectedRoute` tree with the right role/module
  guard, and in `Sidebar.jsx` with the same guard; the server is the real gate.
- Dates: keep ISO `YYYY-MM-DD` for inputs, comparisons, sorting, params and query keys;
  format with `utils/date.js` `fmtDate()` (DD-MM-YYYY) only for display text.
- Quantities and money are computed by the API; the UI displays them (kg from
  litres × 1.0285 is server-side; do not re-derive billing amounts in JSX).
- Styling: Tailwind utilities plus the shared classes in `src/index.css` (Shreeja sky-blue
  theme); no new CSS frameworks or component libraries.
- Print documents (gate pass, COA) are generated by `utils/printDocs.js`; reprints must keep
  the DUPLICATE marking.
- Excel downloads come from the backend as blobs; do not add spreadsheet libraries client-side.
- Check: `cd frontend && npx vite build --logLevel error` must pass before pushing (CI runs
  `npm run build`); there is no lint or test step.
